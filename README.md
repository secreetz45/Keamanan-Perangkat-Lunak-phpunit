# belajar-phpunit

Proyek praktikum Pengenalan PHPUnit (PHP 8.2+, PHPUnit 11).

## Cara pakai
1. Extract zip, lalu di VS Code pilih File > Open Folder > `belajar-phpunit`.
2. Buka terminal VS Code (Ctrl + `) lalu jalankan:
   ```
   composer install
   composer dump-autoload
   vendor/bin/phpunit
   ```
   (Command Prompt Windows: `vendor\bin\phpunit`)
3. Atau tekan Ctrl+Shift+P > "Tasks: Run Test Task" untuk menjalankan test.

Hasil yang diharapkan: `OK (19 tests, 21 assertions)`.
